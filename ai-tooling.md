# AI Tooling Used

AI-assisted development is permitted by the project brief. This project used ChatGPT as a development assistant for:

- breaking the assignment rubric into implementation tasks;
- drafting and reviewing Python modules;
- designing the MCP tool schemas and orchestration flow;
- generating synthetic policy and mock-data content;
- creating tests and evaluation cases;
- reviewing error handling, citations and deployment configuration;
- improving the web UI and demo flow.

The student remains responsible for reviewing, testing and correcting the generated code. No private company data or real employee information is used.

The development process specifically checked the generated implementation against the assignment requirements rather than treating generated code as automatically correct.
