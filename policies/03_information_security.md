# Information Security and Acceptable Use Policy

## Purpose
Employees are responsible for protecting Northstar Digital information, systems and credentials. Security controls apply regardless of whether an employee is working in an office, at home or from an approved temporary location.

## Devices
Company data must be accessed using approved devices and security controls. Employees must keep operating systems and security software current and must not disable required protections.

## Authentication
Passwords must be unique and must not be shared. Multi-factor authentication must be used where provided. Suspected credential compromise should be reported promptly through the security incident process.

## Public and remote environments
Employees should avoid discussing confidential information where unauthorised people can overhear. Screens should be protected from casual viewing and devices should not be left unattended in public places.

## Data handling
Sensitive company information should only be stored and shared through approved systems. Personal email, consumer file-sharing services and unapproved removable media must not be used for confidential company information.

## Security incidents
Lost equipment, suspected phishing, accidental disclosure and suspected account compromise must be reported promptly. Employees should not attempt to conceal an incident or investigate beyond their role if doing so could destroy evidence.
